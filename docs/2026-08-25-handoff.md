## 当前能力

### 1. 受控候选素材查询

入口：`scripts/run_meta_skill.py query`。

配置中必须提供：

```json
{
  "query": {
    "shopId": "报表授权店铺 ID",
    "advertiserId": "广告主 ID",
    "period": {"startDate": "YYYY-MM-DD", "endDate": "YYYY-MM-DD"},
    "topN": 9,
    "dimensionFilters": [],
    "metricFilters": [],
    "sort": {"field": "overall_cost", "direction": "desc"}
  }
}
```

`shopId` 与 `advertiserId` 是不同 ID 域：前者只用于报表连接器授权，后者只用于报表业务参数，不能相互替代。

查询条件之间为 `AND`。字段只能来自 `config/asset-field-registry-v1.json`，不支持任意 SQL、任意 API 字段或原始字段路径。

可用素材维度：

- `material_id`、`material_name`、`material_type`、`video_type`、`anchor_id`。

可用投放指标：

- 原子指标：`overall_cost`、`base_cost`、`overall_order_count`、`net_settlement_order_count`、`net_settlement_amount`、`overall_payment_amount`、`refund_order_count_1h`、`refund_amount_1h`。
- 派生指标：`net_settlement_roi`、`overall_payment_roi`、`net_settlement_rate`、`overall_order_cost`、`net_settlement_order_cost`。

`stat_date` 已移除：新的报表连接器按 `period` 聚合返回，不提供可用于单日筛选的 `stat_time_day` 维度。日期范围必须通过 `period.startDate/endDate` 设置。

`materialId = "-2"` 的 AIGC 动态创意集合会在聚合前排除，并在回执中保留排除原因及源记录数，因为它不能映射为单个素材。

### 2. 直接报表连接器取数

实现位于 `scripts/qianchuan_report_client.py`。它替代了已删除的资产表发现、动态 SQL 和分页路径。

请求契约：

- 网关：`/adg/v1/agent/invoke`
- `function_code`：`OCEANENGINE_UNI_PROMOTION_PLAN_DATA_REQUESTS_ZDY`
- 数据主题：`OVERALL_ROI_LIVE_MATERIAL_VIDEO`
- 支持直接记录列表、`result_type=payload` 和 `result_type=files`。
- 文件结果下载单列 JSON CSV，并写出对应的 `.structured.json`。

运行环境：

- 必填：`ENV_BACKEND_HOST`、`YUCE_AUTHORIZATION`。
- Agent 会话优先级：`YUCE_SESSION_ID`，其次 `YCSESSIONID`，最后 `YUCE_AUTHORIZATION`。
- Cookie 会话优先级：`YCSESSIONID`，其次 `YUCE_AUTHORIZATION`。

不得把这些变量的真实值写入配置、Git、回执、日志或交接材料。网关响应会递归脱敏敏感字段，文件 URL 会去除查询字符串。

### 3. 高光帧策略与抽帧

入口：`scripts/run_meta_skill.py select-frames`。该命令只在已有互动曲线 JSON 和本地视频时抽帧；当前查询命令不会自动获得这两项输入。

可同时配置：`CLICK_COUNT`、`LOSE_COUNT`、`LIKE_COUNT`、`COMMENT_COUNT`、`SHARE_COUNT`、`NEW_FOLLOWER_COUNT`。

- `local_peaks`：选择局部峰值，按指标值降序、时间升序取前 `maxFrames` 个。
- `global_maximum`：只选全局最大值；并列时选更早秒数。
- 同一秒被多个指标选中时，只生成一张 JPEG，但在 `selectionEvidence` 中保留全部证据。
- `includeZeroSecond` 可控制是否包含第 0 秒封面帧。

## 查询工件与停止边界

真实 `query` 成功后只会在指定输出目录创建：

- `source-data/gateway-response.json`：脱敏网关响应。
- 文件型返回时的原始 CSV 与 `.structured.json`。
- `top_materials.json`：候选素材。
- `query-receipt.json`：规范化查询、候选统计、排除记录与 `source.type=direct_material_report`。
- `highlight-policy.json`：已配置高光策略。

查询在候选工件写完后停止。不得在该命令中启动 RPA、下载视频、抽帧、AI 分析或生成报告。

## 使用方式

样例：`config/example-config.json`。其中的 `shopId` 是占位符，实际查询前必须替换。

```bash
cd "/Users/shuzida/Desktop/FDE客户/小仙炖/qianchuan-meta-skill"
python scripts/run_meta_skill.py validate --config config/example-config.json

python scripts/run_meta_skill.py query \
  --config /绝对路径/your-config.json \
  --output-dir /绝对路径/your-run
```

运行 Python 依赖应来自本仓库 `requirements.txt`。之前验证临时复用了原技能目录中的 Python 虚拟环境；新对话应优先在本仓库自己的隔离环境中安装并使用依赖。
